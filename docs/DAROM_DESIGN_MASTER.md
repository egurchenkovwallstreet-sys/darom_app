# Darom — Sky Blue (MASTER)

Единый спокойный стиль на всех экранах. Полные правила: `.cursor/rules/premium-ui.mdc`.

## Токены
- Фон `#F2F8FD`, поверхности `#FFFFFF`
- Акцент `#1C8CF0` (ярко-голубой), градиент `#38C6F7` → `#1468D8`, мягкий `#E2F3FD`
- Текст `#0F1B2D` / `#55657A`
- Track табов `#E6ECF3`, разделители `#E9EEF4`, обводка чекбоксов `#8A99AD`
- Бейджи: основатель `#F3EAD3`, новичок `#E6EEF8`
- Тень одна: `0 4px 20px rgba(0,0,0,0.04)`
- Радиусы: карточки 16, кнопки/инпуты 12, pill 100, нижнее меню 24

## Запрещено
Зелёный и тёмно-синий акцент, коралл/красный/оранжевый, рамки (кроме чекбоксов), цветные тени, стекло (blur), градиенты (кроме brandGradient), тени текста, эмодзи в UI, мерцание, «прыгающая» раскладка.

## Компоненты
- `GlassSurface` — плотная белая карточка с тенью
- `MidnightGlowScreen` — ровный светлый фон
- `AuthHeaderIcon` — шапка экранов приветствия и входа
- `AuthFormScroll` — форма входа без перестроения при фокусе
- `LegalConsentCheckboxes` — белая карточка, крупные видимые галочки, вся строка кликабельна
- `PrimaryActionButton` — сплошная кнопка; `neutralGradient` = белая с тёмным текстом
- `tool/neutralize_shadows.js` — заменяет цветные тени на `cardShadow`
